# 变更日志

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循语义化版本。

## [1.0.0] - 2026-09-23

Minecraft AI Translate 的首个稳定正式版。

### 新增

- 覆盖聊天命令、物品/Lore、告示牌、书本、标题与动作栏、Boss 血条、计分板、实体名称、Dialog、成就、容器、展示实体和玩家列表。
- 新增当前存档/服务器词典与全局词典，支持搜索、编辑、批量添加、导入和导出。
- 新增按存档与服务器隔离的磁盘缓存、缓存管理和优先级翻译队列。
- 新增单键快捷键和界面内原文/译文切换。

### 安全与兼容

- 翻译只作用于渲染副本，不修改游戏数据或出站聊天数据包。
- 保护在线玩家真实名称，同时翻译队伍显示名、前缀和后缀。
- 系统消息跳过 NBT、命令语法、坐标、数值和 Minecraft ID。
- 清理模型返回的 JSON、Markdown、日志和其他非译文包装。
- 空 API Key、网络失败、空缓存目录和无世界上下文均安全回退为原文。

### 修复

- 修复多人聊天协议断连、聊天异步刷新、历史滚动位置和队伍装饰翻译。
- 修复容器标题测量、上锁容器提示、告示牌整块翻译与书页缓存刷新。
- 修复世界切换后缓存/词典当前上下文残留，以及旧世界异步请求串入新世界的问题。
- 回滚会影响普通文本的实验性内部标点保护；保留稳定的 `{water}`、`<Death>` 等整段符号包裹翻译。

### 验证

- 全部自动测试通过。
- 全部文本源渲染入口均有回归连线测试。
- Minecraft 26.1.2 完成全新目录冷启动、空配置、空 API Key 与缓存/词典目录自动创建验证；多存档隔离由自动测试覆盖。
- Minecraft 26.2 与 26.3 完成独立构建、全量自动测试及客户端主菜单启动验证。
